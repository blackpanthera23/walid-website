> How the expanding service range is structured so the brand grows without diluting its

## 1. The "hero + rising pillars" model

Walid is widening beyond minor surgery, but minor surgery is the pillar that earned the
audience (561K TikTok, 1,098 reviews). So we do **not** present four equal columns. We lead
with the hero and present the rest as expert, growing areas.

```
                        ┌───────────────────────────┐
                        │   HERO PILLAR               │
                        │   MINOR SURGERY             │  ← leads everywhere, earned equity
                        │   surgeon-led, day-care     │
                        └───────────────────────────┘
                                     │
                "Also expert in..."  ▼  (rising pillars, smaller weight)
      ┌──────────────────┬──────────────────┬──────────────────┐
      │ AESTHETIC         │ ANTENATAL /       │ [PILLAR 4 — TBD]  │
      │ PROCEDURES        │ WOMEN'S HEALTH    │ placeholder, slot │
      │ (rising)          │ led by Dr Anis    │ ready to fill     │
      └──────────────────┴──────────────────┴──────────────────┘
```

- **Hero pillar (Minor Surgery):** leads the homepage, nav, and proof. Unchanged primacy.
- **Rising pillars (Aesthetics, Antenatal, + 1 TBD):** presented as "also expert in", with
  their own pages, but smaller visual weight than minor surgery at launch.
- **Rebalance later:** as the rising pillars grow, we can promote one to co-lead. The model is
  built to flex; the CMS pillar field (see below) makes rebalancing a content change, not a rebuild.

> **Why:** expanding the brand without throwing away the thing that actually converts. Minor
> surgery stays the front door; the new pillars ride its credibility.

## 4. Specialist display pattern — expertise first, figure as proof

Decided: **lead with the need (service + specialism), then introduce the doctor as the proof.**
Not figure-first (that only works for already-famous names).

```
[ Service + specialism headline ]            ← the need the patient is searching for
   e.g. "Antenatal care, led by a dedicated specialist"
        │
        └─ "led by Dr Anis, [credential / O&G specialism]"   ← the proof the expertise is real
              │
              └─ photo + short bio + "WhatsApp about antenatal"   ← the human + the action
```

Reasoning:
- Patients search the **need** ("pregnancy scan", "aesthetic procedure"), not a doctor's name.
  Headline the service, so we meet the search intent.
- The named specialist + credential + photo turns an abstract claim into a trusted human. The
  person **validates** the expertise.
- Figure-first is weaker for conversion unless the doctor has personal fame / following. If any
  specialist does have a strong personal profile, we can promote them to figure-first case by case.

### Example — Antenatal (Dr Anis)
- Headline: *"Antenatal care, led by a dedicated specialist."*
- Proof line: *"Led by Dr Anis, [O&G credential]."*  `[confirm exact credential]`
- Then: photo, short corporate bio, pregnancy-scan-from-7-weeks note, WhatsApp CTA.
